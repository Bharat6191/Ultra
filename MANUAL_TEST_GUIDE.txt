Create / review flow:

Create new:
1. Open /dashboard/negotiated-rates/new
2. Pick a contractor
3. Pick a Part Master baseline
4. Enter negotiated rate
5. Optionally enter initial rate
6. Optionally upload evidence
7. Save
8. Open the created rate detail page

Add another round:
1. Open /dashboard/negotiated-rates/<rateId>/negotiate
2. Enter agreed rate
3. Add remarks
4. Optionally upload files
5. Save
6. Return to detail page and verify round history

Round workflow rule:
- Round 1 is editable only while status is `draft`
- After `Submit for approval`, negotiation editing stops
- If approver rejects, status becomes `rejected` and that same negotiation can be revised/resubmitted
- After `approved`, user can start the next round again from the approved rate
- That action creates a new draft successor negotiation and opens it
- Example:
  Round 1 draft -> submit -> approved
  Start round 2 from the approved rate -> successor draft -> submit -> approved or rejected
  If that successor is rejected, revise it and resubmit

Approval:
1. Log out from ctr_manager
2. Log in as rate_approver
3. Open /dashboard/tasks
4. Verify pending approval tasks are visible
5. Open a pending task
6. Review the rate details
7. Approve or reject
8. Go back to /dashboard/negotiated-rates
9. Verify status changed

- `INV-MATRIX-REJECTED` was rejected in the exception workflow
