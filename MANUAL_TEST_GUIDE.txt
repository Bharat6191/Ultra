4. Seeded lifecycle scenarios

4.1 Work orders

The current seed creates work-order examples for:
- `draft`
- `pending_approval`
- `rejected`
- `active`
- `closed`
- `cancelled`
- archived / inactive rows

Current UI meaning:
- `pending_approval` shows as `In approval`
- `rejected` shows as `Returned`
- `closed` shows as `Completed`

4.2 Invoices

The current seed creates invoice examples for:
- `INV-MATRIX-DRAFT`
- `INV-MATRIX-SUBMITTED`
- `INV-MATRIX-BLOCKED`
- `INV-MATRIX-PENDING`
- `INV-MATRIX-APPROVED`
- `INV-MATRIX-REJECTED`
- `INV-MATRIX-PAID`
- `INV-MATRIX-CANCELLED`

Meaning:
- `INV-MATRIX-BLOCKED` is blocked but not yet approved
- `INV-MATRIX-PENDING` is in exception approval
- `INV-MATRIX-APPROVED` passed finance approval
- `INV-MATRIX-REJECTED` was rejected in the exception workflow

5. Dashboard checks

Use:
- all_access / DemoPass123!

5.1 Executive overview

1. Log in as `all_access`
2. Open `/dashboard`
3. Verify these cards are shown:
   Contractors
   Negotiation
   Work Orders
   Invoices
4. Verify each card shows:
   top header with icon, title, and subtitle
   one bar chart
   bottom key/value summary
5. Verify the old donut ring / percentage widget is not shown
6. Click inside a chart and verify no green focus box appears

5.2 Chart style

Verify:
1. Bars are straight rectangular bars, not curved
2. X-axis labels are dark / black and bold
3. Y-axis labels are dark / black and bold
4. Invoice chart Y-axis values do not appear clipped as only `000`

5.3 Bottom summary styling

Verify:
1. Labels are centered
2. Labels use title case such as:
   Total Contractors
   Total Negotiations
   Pending Approval
   Total Work Orders
   Total Invoice Value
3. Labels are bold
4. Values are centered and slightly smaller than before

5.4 Invoice toggle

Verify:
1. In the Invoices dashboard card, the toggle order is `Value` then `Count`
2. `Value` is selected by default on first load
3. Clicking `Count` changes the invoice chart and bottom values to count mode
4. Clicking `Value` switches back to amount mode

- the work order remains visible in the `Draft` tab
- opening the detail page shows the `In approval` badge

If no workflow is mapped:
- the work order may auto-activate directly

9.4 Work-order detail

1. Open a work-order detail page
2. Verify contractor name is shown properly
3. Verify work-order status badge text matches the current status mapping

9.5 Inactive work-order activate button

1. Open an inactive work order
2. Verify there is no large header `Inactive` action button
3. Verify there is a bottom footer `Activate` button
4. Click `Activate`

Expected result:
- if the row was previously in approval before it was archived, it should restore to `In approval`
- the record should land back in the `Draft` tab
- if it restores to active state, it should appear in the `Active` tab
