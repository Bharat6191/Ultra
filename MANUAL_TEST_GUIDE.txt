4.4 Negotiated rate flow

Create / edit side:
- ctr_manager / ctr.manager@example.test / DemoPass123!

Approval side:
- rate_approver / rate.approver@example.test / DemoPass123!

Create / review flow:

1. Log in as ctr_manager
2. Open /dashboard/negotiated-rates
3. Verify list loads with dashboard counts
4. Open an existing pending rate or create a new one

Create new:
1. Open /dashboard/negotiated-rates/new
2. Pick a contractor
3. Pick a Part Master baseline
4. Enter negotiated rate
5. Optionally enter initial rate
6. Optionally upload evidence
7. Save
8. Open the created rate detail page

Add another round:
1. Open /dashboard/negotiated-rates/<rateId>/negotiate
2. Enter agreed rate
3. Add remarks
4. Optionally upload files
5. Save
6. Return to detail page and verify round history

Approval:
1. Log out from ctr_manager
2. Log in as rate_approver
3. Open /dashboard/tasks
4. Verify pending approval tasks are visible
5. Open a pending task
6. Review the rate details
7. Approve or reject
8. Go back to /dashboard/negotiated-rates
9. Verify status changed
